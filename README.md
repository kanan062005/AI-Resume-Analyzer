# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that evaluates resumes against a Job Description (JD) using Natural Language Processing (NLP), semantic similarity, fuzzy skill matching, and an explainable ATS scoring engine.

---

## 🚀 Features

- 📄 Resume Parsing (PDF & DOCX)
- 🎯 ATS Score Calculation
- 🧠 Semantic Similarity using Sentence Transformers
- ✅ Weighted Fuzzy Skill Matching
- 📊 Resume Completeness Analysis
- 📑 Resume Section Analysis
- 💡 AI-based Resume Improvement Suggestions
- 🔍 Gap Analysis between Resume and Job Description
- 📈 Estimated ATS Score after Improvements
- 🌐 Interactive Streamlit Dashboard

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/kanan062005/AI-Resume-Analyzer.git
```

Move into the project

```bash
cd AI-Resume-Analyzer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```

8. Get Resume Improvement Suggestions
